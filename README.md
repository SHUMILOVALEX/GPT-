# Точка анализа

Авторская образовательная платформа на русском: 12 недель бизнес- и системного анализа с нуля при нагрузке 15–20 часов в неделю. Один сквозной учебный проект — сервис записи на занятия.

## Запуск

Нужен Python 3.10+; для автоматических проверок — Node.js 18+. Внешних зависимостей, API-ключей и установки пакетов нет.

```sh
cd /workspace/GPT-
npm start
```

Сервер слушает порт 3000. Для локального открытия в браузере используется адрес `http://localhost:3000`. ES-модули требуют HTTP-сервера: открытие `index.html` через `file://` не поддерживается. В облаке используйте способ доступа к порту, поддерживаемый вашей средой; эта инструкция не создаёт публичную ссылку.

## Что есть

- 12 блоков: 48 объяснений, таблицы терминов, схемы связей и разобранные примеры.
- 36 авторских заданий с критериями и ориентирами для самопроверки.
- 60 карточек с простым интервальным расписанием и 24 вопроса самопроверки.
- Ответы, отметки, результаты и расписание сохраняются в localStorage.
- Экспорт резервной копии JSON, импорт с проверкой формата, экспорт работ в Markdown.
- Поиск по содержанию, тематическая библиотека по пользовательской подборке.
- Исполняемый SQL-практикум SQLite на фиксированных данных.

## Проверки

```sh
npm test
python3 tools/sql_lab.py
# Добавьте свои SELECT-запросы в sql/exercises.sql:
python3 tools/sql_lab.py --query-file sql/exercises.sql
```

Запуск с пустым файлом упражнений намеренно не считается успешным выполнением практики. Каждый запуск SQL создаёт чистую БД в памяти. Практикум не проверяет специфичные для PostgreSQL блокировки и изоляцию.

## Методика

Неделя: 4 ч теории, 8 ч практики, 2 ч повторения, 2–6 ч разбора/чтения; это ориентир. Прогресс блока: теория, три самостоятельные работы и оба верных ответа короткого теста. Отметки работ — самооценка, не внешняя проверка. Карточки не заменяют практику. Учебные числа не являются измеренными бизнес-результатами.

Библиография основана на подборке пользователя и тематически связана с блоками. Полные тексты книг не предоставлялись, сверка изданий/страниц не выполнялась. Теория, задания и карточки написаны своими словами, точные цитаты и главы не приписываются авторам. Книги по вниманию и коммуникации служат поддержкой, а не обязательной нагрузкой. Основы UML/BPMN/C4 требуют дальнейшей практики в редакторе; схемы в конспектах — обзорные, не формальные диаграммы.

## Ограничения

Это работающая самостоятельная платформа для одного учащегося, без сервера аккаунтов, синхронизации устройств, автоматического ментора, проверки свободных ответов или реализации сервиса бронирования. SQL выполняется в CLI, а не в браузере. Для обратной связи нужен человек. Курс даёт базу и учебный кейс, не гарантию трудоустройства и не полную замену практическому опыту.

Данные хранятся только в браузере на текущем origin: другой порт, домен, очистка данных или приватный режим могут сделать их недоступными. Регулярно экспортируйте JSON. Markdown — документ портфолио, не файл восстановления. Импорт заменяет прогресс после подтверждения и предварительного скачивания резервной копии. Не храните в ответах секреты и реальные персональные данные.

## Разработка

`course.js` — учебный контент, `state.js` — расчёт прогресса/расписания и валидация, `app.js` — интерфейс. `sql/` и `tools/sql_lab.py` — практикум. Сборка не нужна. Пользовательский текст экранируется перед вставкой в HTML.

Для будущих облачных задач используйте существующую копию `/workspace/GPT-`: задача уже изолирована, дополнительный Git worktree не нужен.
